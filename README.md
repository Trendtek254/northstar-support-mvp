# Northstar Support MVP

## Overview

Northstar Support MVP is a Python-based project currently in early setup. This README will be expanded as the project's features and architecture take shape — see `CHARTER.md` for team and project context.

## Requirements

- Python 3.10+
- pip

## Setup

```bash
git clone https://github.com/Trendtek254/northstar-support-mvp.git
cd northstar-support-mvp

python -m venv venv
source venv/bin/activate   # on Windows: venv\Scripts\activate

pip install -r requirements.txt
```

## Running Tests

Tests live in the `tests/` folder and use `pytest`.

```bash
pip install pytest
pytest
```
